# RUSH SIMULATOR — Beta

スマホ向けのカスタマイズ可能なRUSH/STシミュレーター（ベータ版）です。

## 公開方法（GitHub Pages）
1. GitHubで新しい **Public** リポジトリを作成します。
2. このフォルダ内のファイルを**すべてリポジトリのルート**にアップロードしてコミットします（ZIPそのものではなく、展開したファイル）。
3. リポジトリの **Settings → Pages** で **Deploy from a branch** を選択します。
4. Branch: **main** / Folder: **/(root)** を指定して保存します。
5. 公開URL `https://<ユーザー名>.github.io/<リポジトリ名>/` にアクセスします。反映には数分かかる場合があります。

## 起動
- スマホ: 公開URLを開くとスマホ向け画面が表示されます。
- PC: `index.html` を開くとスマホサイズのプレビューが表示されます。
- `app.html` はシミュレーター本体です。

## 機能
- ST回転数・大当たり確率・出玉振り分け設定
- 先バレ ON/OFF、信頼度25%・40%・99%
- 手動・自動・一括消化
- 図柄縦回転、保留演出、BGM・動画背景・効果音
